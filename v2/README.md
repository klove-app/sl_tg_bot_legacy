# RunTracker Bot v2

Чистая версия Telegram-бота для группового учёта пробежек. Рейтинги и статистика
изолированы по `chat_id`; данные разных групп не смешиваются.

## Команды

- `@runforestsweaty_bot 5.2` — записать 5,2 км
- `@runforestsweaty_bot 10 утренний парк` — записать пробежку с заметкой
- `/journey` — общая карта пути группы к Монблану
- `/top` — рейтинги лиг за неделю, текущий или предыдущий месяц
- `/me` — личная статистика за неделю и месяц в текущей лиге
- `/undo` — удалить свою последнюю запись после подтверждения
- `/help` — помощь

Команда `/run 5.2` сохранена только для обратной совместимости. Обычный способ
регистрации — упомянуть бота и написать дистанцию без дополнительной команды.

Лига закрепляется за участником на календарный месяц. Новые участники начинают
в «Тропе»; на границе месяца до двух активных лидеров «Тропы» меняются местами
с нижней частью «Темпа». Каждый понедельник в 09:00 бот публикует итоги закрытой
недели, а первого числа в 09:10 — итоги закрытого месяца. Время определяется через
`BOT_TIMEZONE`.

## Звания и медали

`/me` показывает текущее звание участника: «Новая ячейка», «На связи»,
«Полевой сотрудник», «Вне эфира», «Спящая ячейка» или «Снова в эфире».
«Спящей» ячейка становится после 60 дней без пробежек.

Постоянные медали выдаются за личные дистанции 2/5/10 км, возвращение «с
дивана» и последующее закрепление привычки, три пробежки, четыре активные недели
подряд, а также за 100/500/1000 км суммарно. Новая медаль показывается в ответе
на пробежку; уже полученные медали доступны в `/me`. Старая история учитывается
автоматически и без сообщений в чат.

В ежемесячном итоге бот также объявляет «Держит Темп», «Хозяина Тропы» и
перечисляет спящие ячейки.

## Из Кубани к Монблану

Все неудалённые пробежки группы с 1 января по 31 декабря 2026 года складываются
в общий путь длиной 2 500 км: Парк Краснодар → Чёрное море → Карпаты → Дунай →
Альпы → Шамони. После каждой новой пробежки бот отвечает актуальной картой,
общим процентом и расстоянием до следующей точки. `/journey` показывает карту в
любой момент, а `/undo` сразу пересчитывает прогресс.

Контрольные точки на 500/1000/1500/2000/2500 км объявляются в чате один раз.
История 2026 года входит в маршрут автоматически; уже пройденные до обновления
точки фиксируются без старых поздравлений. Текущий прогресс также входит в
еженедельные и ежемесячные итоги. Карта строится локально внутри бота и не требует
Stability, геокартографического API или дополнительных секретов.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python -m app.main
```

Нужны новый токен от `@BotFather` и PostgreSQL `DATABASE_URL`. Не используйте
токены, которые когда-либо попадали в GitHub, чат или скриншоты.

## Тесты

```bash
pytest
ruff check .
```

## Railway

Создайте новый service из этой ветки и укажите Root Directory `/v2`. Переменные:

- `TELEGRAM_BOT_TOKEN`
- `DATABASE_URL` (ссылка на существующий Railway Postgres)
- `BOT_TIMEZONE`, например `Europe/Moscow`
- `MAX_DISTANCE_KM`, по умолчанию `100`
- `ALLOWED_CHAT_IDS` — необязательный allow-list через запятую
- `SUMMARIES_ENABLED` — включает автоматические итоги, по умолчанию `true`
- `SUMMARY_HOUR` — час публикации итогов, по умолчанию `9`
- `MONTHLY_SUMMARY_MINUTE` — минута месячного итога, по умолчанию `10`

При первом старте обновлённой версии SQLAlchemy создаст только новую таблицу
контрольных точек `runbot_journey_milestones`; существующие таблицы пробежек и
подключённая PostgreSQL-база остаются прежними.

Для staging используйте отдельного Telegram-бота. Не запускайте legacy и v2 с
одним токеном одновременно.

## Перенос legacy-данных

Сначала только просмотр:

```bash
python -m scripts.import_legacy
```

После проверки количества строк:

```bash
python -m scripts.import_legacy --apply
```

Можно ограничить импорт одной группой через `--chat-id`. Импортируются только
строки с `chat_id`; повторный запуск безопасен.
